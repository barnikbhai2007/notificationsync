Set up both phones

  1. Connect both phones to the same Wi-Fi network.
  2. Install the APK on both. If you have 2.0.1 or 2.1.0, update directly; uninstall 1.x or 2.0.0 builds first.
  3. On Phone A, leave the default role. It hosts the room and shows a host address.
  4. On Phone B, tap Switch to Phone B. It finds Phone A automatically, or tap Scan.
  5. Grant notification listener, phone, call log, and contact access so alerts and caller names appear.
  6. Allow Display over other apps on both phones so clipboard sync works while you are in any app.
  7. Accessibility is optional now — enable it only as a clipboard backup.
  8. The status pill turns Linked when both phones connect.
