Set up both devices

  1. Connect both devices to the same Wi-Fi network.
  2. Install the APK on both. Builds from 2.0.1 onward update directly; uninstall 1.x or 2.0.0 builds first.
  3. Open Devices on the device that should host. It shows a QR code and pairing code.
  4. On the other device open Devices → Scan QR code and scan it. It connects directly over Wi-Fi.
  5. Grant notification access and Display over other apps on both devices. Phone access is requested only on the device with the SIM.
  6. Accessibility is optional — enable it only as a clipboard backup.
  7. The status pill turns Linked when both devices connect.
